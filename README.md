# Pro Drive – אתר תיווך רכב

React + Vite + TypeScript, תלת-ממד ב-React Three Fiber, אנימציות גלילה ב-GSAP (ScrollTrigger, SplitText, Flip) וגלילה חלקה ב-Lenis. האתר בעברית, מימין לשמאל (RTL).

## הרצה

```bash
npm install
npm run dev
```

לבניית גרסה לפרסום: `npm run build`. התוצאה נוצרת בתיקייה `dist/`.

## איפה עורכים מה

| מה | קובץ |
|---|---|
| טלפון, וואטסאפ, מייל ושעות | `src/data/site.ts` (`SITE`) |
| חבילות ומחירים, שאלות נפוצות | `src/data/site.ts` (`PACKAGES`, `FAQ`) |
| עמוד "מי אני" (שם, סיפור, ציוני דרך, ערכים) | `src/data/site.ts` (`FOUNDER`). כרגע טקסט לדוגמה |
| תמונת הבעלים | שמים `public/img/founder.jpg` ומגדירים `photo: "founder.jpg"` |
| רכבי הקטלוג | `src/data/cars.ts` (פיקטיביים, עם "המוכר ביקש" ו"מחיר יעד") |
| עיצוב: צבעים, גופן, רדיוס | המשתנים בראש `src/site.css` |

## הקונספט

עיצוב בהיר (אפור בטון, לא לבן), עם אדום מירוצים כצבע הדגשה וכותרות צרות שנוטות קדימה, כמו מהירות. הכפתורים, התגיות ומסגרות התמונות נטויים באותה זווית.

## הרכב התלת-ממדי

- **המודל:** `public/models/car.glb`. זה מודל "Car Concept" ברישיון CC BY 4.0. הקרדיט מופיע בפוטר, ואסור להסיר אותו. דחסתי אותו מ-11.8MB ל-2.8MB.
- **תאורת הסטודיו:** `public/hdri/studio_small_03_1k.hdr`, מ-Poly Haven ברישיון CC0 (חופשי לשימוש, בלי צורך בקרדיט).
- **הקוד:** `src/three/RealCar.tsx`. הקובץ מטפל בצבעי הצבע, בדלתות המספריים, במכסה הקדמי, בגלגלים ובלוחית "PRO·DRIVE". הוא גם מסתיר את הלוגואים שהגיעו עם המודל.
- **דף הנחיתה:** הפונקציה `HeroCatalog` ב-`src/pages/Landing.tsx`, והכביש ב-`src/three/RoadHero.tsx`. העמוד הוא כביש, הכותרת צבועה על האספלט, והרכב עומד בפרופיל פונה ימינה. בגלילה הדלת נפתחת, המצלמה נכנסת דרכה לתוך הרכב, ואז הקטלוג עולה והכרטיסים זזים הצידה. הכותרת שצבועה על הכביש מגיעה מהקבועים `TITLE` ו-`SUB`.
- **תאורת השמיים:** `public/hdri/quarry_01_1k.hdr`, מ-Poly Haven ברישיון CC0.

## חידוש תמונות הרכב

כל התמונות ב-`public/img` הן רינדורים של המודל. כדי לייצר אותן מחדש:

```bash
npm run dev
node scripts/render-stills.mjs shots.json public/img
```

לפני ההרצה צריך להכין קובץ `shots.json` עם רשימת הצילומים. הפורמט מתואר בראש הסקריפט. הסקריפט מייצר קבצי PNG, וכדי שהתמונות יופיעו באתר צריך להמיר אותם ל-`.webp` עם אותו שם, כמו התמונות הקיימות.

## אחסון

האתר הוא אפליקציית עמוד יחיד (SPA), ולכן השרת צריך להפנות כל כתובת ל-`index.html`. בלי זה, כניסה ישירה לכתובת כמו `/catalog` תחזיר שגיאה. ההגדרה הזאת כבר מוכנה עבור Netlify (`public/_redirects`) ועבור Vercel (`vercel.json`).
