# Pro Drive – אתר סוכנות רכב

React + Vite + TypeScript, תלת-ממד ב-React Three Fiber, אנימציות גלילה ב-GSAP (ScrollTrigger, SplitText, Flip) וגלילה חלקה ב-Lenis. האתר בעברית, מימין לשמאל (RTL).

## הרצה

```bash
npm install
npm run dev
```

לבניית גרסה לפרסום: `npm run build`. התוצאה נוצרת בתיקייה `dist/`.

## איפה עורכים מה

| מה | קובץ |
|---|---|
| טלפון, וואטסאפ, מייל, כתובת ושעות פעילות | `src/data/site.ts` (האובייקט `SITE`) |
| עמוד "עלינו": שם, תפקיד, ציטוט, הסיפור, ציוני דרך וערכים | `src/data/site.ts` (האובייקט `FOUNDER`). כרגע הכול טקסט לדוגמה (שם, סיפור, כתובת) שצריך להחליף |
| תמונת הבעלים | שמים קובץ `public/founder.jpg` ומגדירים `photo: "/founder.jpg"` |
| רכבי הקטלוג | `src/data/cars.ts`. כל הדגמים כרגע **פיקטיביים** |
| תמונות הרכבים | `public/cars/<id>.png`. כרגע אלה רינדורים של מודל התלת-ממד; אפשר להחליף בתמונות אמיתיות (יחס 16:10) |
| טקסטים בעמוד הבית | `src/pages/Home.tsx` |
| צבעים וגופנים | המשתנים בראש `src/styles.css` (`--accent` הוא צבע הזהב) |

## הרכב בעמוד הבית

- `src/three/CarModel.tsx`: מודל רכב מקורי שנבנה בקוד, בלי קבצים חיצוניים. יש בו שלושה סוגי מרכב: `sedan` (סדאן), `suv` ו-`coupe` (קופה).
- `src/three/HeroScene.tsx`: הסצנה (תאורת סטודיו, רצפה מחזירת אור וכביש).
- כוריאוגרפיית הגלילה נמצאת ב-`src/pages/Home.tsx`, בפונקציה `Hero`. האזור ננעל למשך כ-3 גובהי מסך, ובזמן הזה:
  1. הרכב מסתובב מזווית חזית-צד לפרופיל צד מלא.
  2. הכביש זז מתחתיו, הגלגלים מסתובבים והפנסים נדלקים.
  3. הרכב מפנה את החזית ונוסע אל מחוץ למסך.
- **החלפה במודל אמיתי:** אפשר לטעון קובץ `.glb` עם `useGLTF` מ-`@react-three/drei` במקום `<CarModel>`. ההנפשה תמשיך לעבוד, כי היא מזיזה את הקבוצה (`group`) שעוטפת את המודל.
